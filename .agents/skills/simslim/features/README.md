# Feature map

One file per user-facing feature. Each file says what the feature is, how a user reaches it, how to drive it with `xcodebuildmcp`, and what end state proves it works. Add a file when a feature ships, and fix a file when a drive shows it is wrong.

| Feature | File |
|---|---|
| Focus session: start, pause, resume, end | [focus-session.md](focus-session.md) |
| Sessions history | [sessions-history.md](sessions-history.md) |
| Subjects editor | [subjects-editor.md](subjects-editor.md) |

Not mapped yet: Social, Groups and the Focus Design Lab. They run on mock data, so map them when they gain real behaviour.
